# Spring AI Handbook — Table of Contents

AI for Backend Developers

Since you have already covered AI Fundamentals, Generative AI, Prompt Engineering, RAG, Agentic AI, and MCP, this handbook should focus on implementing these concepts using Spring AI, along with the essential Spring AI features.

## Part 1 — Spring AI Fundamentals

1. Introduction to Spring AI — What it is, why it is needed, architecture, and comparison with LangChain.
2. Spring AI Setup — Spring Boot project setup, dependencies, configuration, and API keys.
3. Spring AI Core Components — `ChatModel`, `ChatClient`, `Prompt`, `Message`, `ChatResponse`, and model providers.

## Part 2 — Building AI Applications

4. ChatClient and Prompt Engineering — System prompts, user messages, prompt templates, and dynamic prompts.
5. Structured Output and Streaming — Mapping responses to Java POJOs, JSON output, and streaming with reactive APIs.
6. Chat Memory — Conversation history, `ChatMemory`, and multi-turn conversations.
7. Tool Calling — Using `@Tool` to invoke Java methods, Spring services, and external APIs.

## Part 3 — RAG and Vector Databases

8. Embeddings and Vector Stores — `EmbeddingModel`, `VectorStore`, semantic search, and PGvector.
9. Document Ingestion and RAG — Document loading, chunking, embedding, retrieval, and generating context-aware answers.

## Part 4 — Agents and MCP

10. Building AI Agents — Combining LLMs, tools, memory, and multi-step execution.
11. Spring AI and MCP — MCP clients and servers, tool discovery, and integration with existing MCP servers.

## Part 5 — Production-Ready Spring AI

12. Advisors and Advanced Capabilities — Advisors API, RAG advisors, multimodal AI, and model selection.
13. Testing, Observability and Security — Testing AI responses, tracing, token usage, prompt injection, and tool security.
14. Deployment and Best Practices — Docker, Kubernetes, error handling, retries, performance, and cost optimization.

## Hands-On Projects

- Project 1: AI Chat REST API using Spring Boot and an LLM.
- Project 2: Chat with PDF Documents using Spring AI and PGvector.
- Project 3: AI Agent with Java Tools and MCP integration.

Recommended approach: Keep the handbook focused on these 14 chapters and three projects. Explain AI theory briefly where necessary, and spend most of the content on Spring AI APIs, Java code examples, and practical implementation.
